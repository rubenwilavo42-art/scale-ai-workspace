# ScalAI V1.2 — MCP & Connexions

Cette étape conserve le système MCP existant et ajoute une barrière de validation dans le processus principal.

## Protections

- noms de connexions MCP validés contre les caractères de shell et les chemins ;
- connexions distantes en HTTPS uniquement, avec HTTP limité à localhost pour le développement ;
- validation stricte des variables d'environnement ;
- blocage des variables capables de modifier le chargement de Node/dylib (`NODE_OPTIONS`, `LD_PRELOAD`, etc.) ;
- contrôle du scope `project` / `user` ;
- un scope projet exige un dossier réellement accessible ;
- les secrets MCP ne sont jamais renvoyés au renderer : seuls les noms des variables sont exposables ;
- les bundles MCP ne peuvent être utilisés comme connexions qu'à partir du répertoire géré par ScalAI ;
- les déconnexions valident également l'identifiant avant de toucher aux fichiers.
