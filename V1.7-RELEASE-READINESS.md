# ScalAI V1.7 — Release readiness

## Objectif

Préparer une validation réelle sur macOS sans considérer les tests spécifiques à macOS comme validés depuis Linux/Windows.

## Changements

- Identité de build review passée de Nami à ScalAI.
- Workflow de release utilise désormais le dépôt GitHub courant (`github.repository`) au lieu d'un dépôt Nami codé en dur.
- Artefacts et contrôles du workflow utilisent `ScalAI.app`.
- Ajout d'un workflow CI séparant validation Linux et validation macOS.
- Télémétrie de lancement désactivée par défaut : aucune requête réseau de télémétrie sans `SCALAI_PING_URL` explicitement défini.
- Variables de debug opérationnelles renommées `SCALAI_*`.

## Règle de validation

Une validation macOS n'est considérée comme réelle que lorsque le job `macos-validation` a exécuté `npm ci`, `npm test`, l'audit de sécurité, le packaging et `check-bundle.mjs` sur un runner macOS.

La CI Linux ne remplace pas cette validation.
