# ScalAI V1.3 — Browser agent

Ajout d’un niveau d’accès explicite pour le navigateur partagé par session.

- `observe` : lecture/navigation non mutante ; les outils de clic, saisie, drag, sélection, dialogue et évaluation sont exclus du schéma MCP et refusés côté serveur.
- `interact` : comportement complet conservé pour compatibilité.
- Le mode est associé à la session ScalAI et retourné par `browser:connection`.
- Le serveur MCP revalide le mode à chaque appel.

Le navigateur continue d’utiliser les profils ScalAI, les limites de navigation existantes et les contrôles de workspace/local HTML déjà présents.
