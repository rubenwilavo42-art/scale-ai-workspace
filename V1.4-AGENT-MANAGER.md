# ScalAI V1.4 — Gestionnaire d’agents

Cette version formalise la fiche de chaque agent : détection, chemin résolu,
version, statut de connexion et capacités vérifiées.

## Principes
- Le renderer ne reçoit jamais de secret.
- La version est demandée au binaire résolu avec `--version`, sans shell.
- Les actions d’installation, connexion, déconnexion et diagnostic restent des
  commandes explicites de l’agent ; ScalAI ne demande pas le mot de passe du
  fournisseur.
- Une capacité n’est affichée comme disponible que si la registry ScalAI possède
  une commande vérifiée pour elle.
- L’état « installé » et l’état « connecté » restent distincts.

## États UI
- Non installé
- Installé — connexion inconnue
- Installé — déconnecté
- Installé — connecté
- Version disponible / inconnue
- Action en cours dans une session terminal

## Prochaine validation
La validation d’installation et des authentifications doit être refaite sur
macOS réel avant release, notamment pour Apple Silicon, Keychain et les CLIs
présents dans le PATH du shell utilisateur.
