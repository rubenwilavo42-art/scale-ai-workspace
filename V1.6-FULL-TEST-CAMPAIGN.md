# ScalAI V1.6 — Campagne de tests et audit

## Objectif
V1.6 est une étape d'audit : elle ne modifie pas les règles métier déjà validées. Elle vérifie la cohérence de V1.5 et prépare la validation macOS réelle.

## Résultats exécutés dans l'environnement Linux courant

- Suite complète : **1284 / 1298 tests passés**.
- Tests échoués : **14**.
- Syntaxe JavaScript main + renderer : **OK**.
- Le smoke test Electron n'est pas déclaré validé : les dépendances Electron n'étaient pas disponibles dans l'environnement au moment du test.
- `npm ci --ignore-scripts` a dépassé le délai de l'environnement d'exécution ; aucune installation partielle n'est considérée comme une validation.
- L'audit `check-security.mjs` n'a pas produit de verdict exploitable : l'audit des dépendances a expiré. Aucun résultat de sécurité n'est donc présenté comme validé.

## Échecs classés

### Environnement / plateforme

- Tests dépendant de `/bin/zsh` : **7 échecs** (`ENOENT`), car zsh n'est pas installé dans l'environnement courant.
- Tests macOS / packaging : notarisation et review build : environnement non-macOS.
- Tests d'updater/repository shape : certains contrôles dépendent de l'état du dépôt ou des artefacts de packaging.

### Régressions à revalider sur environnement complet

Les tests suivants ont échoué dans la suite et doivent être rejoués sur une machine avec les dépendances complètes avant de considérer V1.6 comme une validation finale :

- screenshot / changement de document pendant capture ;
- invalidation de permissions pour appels browser en file d'attente ;
- extraction de bundle ;
- un cas de lancement d'agent dépendant du shell ;
- notarisation DMG ;
- repo-shape ;
- review-build ;
- updater-yaml.

Ces échecs ne sont **pas** transformés en "pass" simplement parce qu'ils sont probablement liés à l'environnement.

## Règles UX de permissions revalidées

- **Autoriser une fois** : une seule action.
- **Autoriser pour la session** : couvre les opérations normales de la même capacité pour le même agent dans le même workspace.
- Une nouvelle demande peut apparaître en cas de changement d'agent, workspace ou capacité.
- Une sortie du workspace reste bloquée indépendamment des grants.
- Aucun prompt répétitif pour chaque commande normale déjà autorisée.
- Les credentials restent hors du renderer.

## Notifications revalidées

- Notification de fin uniquement lorsque la fenêtre est en arrière-plan.
- Pas de notification pour une fenêtre au premier plan.
- Pas de notification pour un arrêt volontaire.
- Les secrets et le contenu du terminal ne sont pas inclus.

## Critères de sortie V1.6

Avant validation finale :

1. installer les dépendances avec succès ;
2. exécuter `npm test` sans les erreurs d'environnement ci-dessus ;
3. exécuter `npm run check:security` avec un résultat explicite ;
4. lancer le smoke test Electron ;
5. effectuer un passage manuel de l'interface ;
6. effectuer la validation macOS réelle pour `.app`, Finder, notifications, permissions et packaging.
